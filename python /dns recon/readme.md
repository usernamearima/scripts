# DNS Recon Tool
Simple DNS reconnaissance tool written in Python for quick domain information gathering during penetration testing and OSINT reconnaissance.

---

## Features
- DNS record enumeration (A, AAAA, MX, NS, TXT, CNAME)
- Basic subdomain brute forcing
- Lightweight and fast
- Useful for quick recon during pentesting

---

## Installation
```bash
pip install dnspython
```

---

## Usage

```bash
python dns_recon.py domain.com
```

## Disclaimer
This tool is intended for **educational purposes and authorized security testing only**.  
Do not use it against systems without permission.
