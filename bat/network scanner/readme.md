# 🌐 Network Scanner (Batch)

Simple **Batch script** that scans a `/24` subnet and shows active hosts using `ping`.

## Usage
```scanner.bat```

## Enter subnet (example):
```192.168.1```

## The script scans:
```192.168.1.1 – 192.168.1.254```

**Purpose:** basic network discovery and learning.

## ⚠️ Use only on networks you own or have permission to scan.
